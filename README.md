# Dig Dig Dig!

An endless runner where you pilot a shovel deeper and deeper underground. Through the crust, into the mantle, and down to the core.

**[▶ Play it here](https://ih8quicksand.github.io/Dig-Dig-Dig/)**

*(screenshot here)*


## How to Play

Use the **arrow keys** to dodge obstacles as you dig deeper. Grab oil to speed up, avoid TNT or it's game over. How deep can you get?

## About

Made for my Phaser3 game development class at UCSC. All assets were created by sourcing 3D models and rendering them in Blender with a pixelate compositor shader to get the pixel art look. Each sprite — the shovel, TNT, and oil — is a seamlessly looping animation rendered from a texture atlas. The scrolling background is a seamless tileable texture from Polyhaven, also rendered in Blender.

The further you dig, the more the environment changes, try and see them all!
